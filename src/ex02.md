## Время

### 4. Сколькими способами в журнале записано время и сколько строк в каждом?

**Ответ:** в журнале **два формата** записи времени:
- `YYYY-MM-DD HH:MM:SS` — **858 строк**;
- `DD.MM.YYYY HH:MM:SS` — **143 строки**.

**Чем получено:**
```sql
SELECT CASE
         WHEN substr(ts, 5, 1) = '-' THEN 'YYYY-MM-DD HH:MM:SS'
         WHEN substr(ts, 3, 1) = '.' THEN 'DD.MM.YYYY HH:MM:SS'
         ELSE 'неизвестный формат'
       END AS timestamp_format,
       COUNT(*) AS rows
FROM access
GROUP BY timestamp_format
ORDER BY timestamp_format;
```
